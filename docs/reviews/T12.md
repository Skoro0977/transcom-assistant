# Независимое ревью T12

Проверены конвейер анализа, подтверждения, версии, транзакции, проектный доступ, основания, изменения UI и миграции.

Два P2 исправлены:

- При ручной правке оставался отпечаток старого содержания. Создание и исправление используют общий нормализованный fingerprint, коллизия исправления отклоняется. Проверены A->B->повтор A и повтор B.
- Два участника могли создать два задания анализа одной редакции. На SQLite постановка сериализована до поиска; уникальность version_id/kind закреплена в БД. Повтор возвращает существующее задание.

Повторное независимое ревью сняло оба замечания для текущего локального SQLite-профиля. Девять критичных проверок прошли, после изменений две целевые регрессии прошли повторно. Реальный GigaChat-3-Lightning создал проверенное предложение, не приняв его автоматически. Отдельная проверка активной модели также успешна: OAuth, модели, генерация, Embeddings1024. Совместимость PostgreSQL должна проверяться при будущем серверном переходе, согласно ADR001.
