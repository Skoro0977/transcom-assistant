# Независимое ревью T13

Найдены и исправлены P1 и P2:

- P1: старый исполнитель мог записать текст/цитату после archive/purge. Все завершающие пишущие фазы читают состояние под SQLite write_lock, проверяют статус и timestamp задания. Вложение и связь с письмом записываются атомарно внутри ingest. Ветки ошибки также не оживляют отмененное задание. Добавлена двухпоточная регрессия: удаление начинается после повторного чтения lifecycle, ждет публикацию под блокировкой, затем очищает результат.
- P2: restore не возобновлял отмененный parse. Отмененные разборы возвращаются в очередь, analyze получает новый timestamp и курсор0, старый исполнитель не изменяет новую очередь.

Повторное независимое ревью сняло P1/P2 для SQLite. Целевые проверки: удаление двух редакций, чужой токен, повторное согласие, физическая очистка, подавление повторного импорта, сохранение принятого решения с удаленной цитатой, история и восстановление разбора. Реальные документы не удалялись.
