# Независимое ревью T14

Существенных замечаний нет. Проверены проектный доступ, текущие/исторические редакции, исключение архива, purge, запоздалый эмбеддинг, модель и размерность. Независимый ревьюер подтвердил соответствие EmbeddingsGigaR официальной документации и не запускал передачу корпуса.

Локальный индекс4807 фрагментов и поиск на реальном архиве проверены. Семантическое ранжирование проверено через реальный GigaChat только на искусственных фразах. Критичные проверки истории/ACL/архива/purge во время эмбеддинга проходят. Массовая облачная обработка ожидает прямое разрешение пользователя, флаг по умолчанию false. Автоматический проверяющий дважды отклонил запуск с корпусом; обходов нет.
