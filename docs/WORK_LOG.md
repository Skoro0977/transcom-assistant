Принятые решения проекта сохраняются, удаленная цитата отмечается явно.

Проверены на искусственных данных: нельзя удалить активный документ, неправильная фраза/чужой токен не удаляют файл, после подтверждения скачивание закрыто, физическая очистка удаляет blob, повторная загрузка блокируется, автоматический импорт подавляется. История редакций и разница срока проверены, сборка/ruff/Alembic check успешны. Реальные документы не удалялись. T13 на независимом ревью.
