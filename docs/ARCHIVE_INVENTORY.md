# Архив и окружение

Архив по поручению пользователя перенесен из D:\Desktop\Сбер кейс в data/source_archive внутри проекта на D. Файлы не изменялись. 207 файлов, 348847984 байта, 5 повторных копий по SHA-256. Полный манифест с хэшами находится в data/source_inventory.json и исключен из Git.

Форматы: 97 PDF, 38 MSG, 30 DOCX, 27 XLSX, 7 PNG, 3 DOC, по одному JPG, RTF, DXF, KML, LOG. Пять фактических категорий: ТЗ/договор, ТУ, официальные письма, Outlook-переписка, отчеты. Наличие DOC и изображений требует отдельной подготовки/OCR. DXF/KML сохраняются как исходники; инженерная проверка чертежей не входит в задачу.

На C доступно около 4.2 ГБ, на D около 228.5 ГБ. Найдены Git на D, Node 20.12.2 и Python. Docker, PostgreSQL, OCR и офисный конвертер не обнаружены через PATH/сервисы. Это не утверждение об отсутствии программ во всех папках компьютера. Не выполняется глобальная установка. Временные файлы и кэши задаются scripts/dev-env.ps1, который также переводит рабочую папку на D.

Безопасность: инвентаризация читает байты и вычисляет хэши, не открывает документы в офисных программах и не выполняет активное содержимое. Содержимое будет разбираться ограниченными парсерами на отдельном этапе. Антивирусное заключение не заявляется.
