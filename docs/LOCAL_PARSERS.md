# Локальные разборщики

OCR работает на этом ПК без облака: Tesseract.js7.0.0, русская и английская модели1.0.0 в tools/ocr. npm ci --ignore-scripts устанавливает закрепленные пакеты на D. Путь OCR_NODE задается в .env, текущий runtime D:/CodexData/Runtimes/node/node-v26.13.1-win-x64/node.exe. Кэш моделей data/local/ocr-cache. Отсутствующий инструмент дает явную подготовку, не сетевую загрузку.

PDFium рендерит до12Мпикс на страницу, OCR принимает изображения до20Мпикс. Общий бюджет OCR180с, до20 страниц за файл, отдельная попытка45с. Внешний парсер240с,768МиБ. При недостатке времени сохраняется частичный текст, оригинал доступен. Уверенность OCR не доказывает правильность чисел, сверяйте оригинал перед подтверждением.

Word97+ читается из таблицы текстовых блоков. Макросы, поля, встроенные объекты и офисное приложение не запускаются. Зашифрованные/старые/поврежденные DOC требуют подготовки. XLS читает сохраненные значения, формулы не вычисляет. DXF и KML дают только подписи, не проверку геометрии/масштаба/инженерных расчетов. XML external entities запрещены.

Первая попытка конвертации одного DOC через LibreOffice достигла тайм-аута, этот путь исключен из итогового кода. LibreOffice на D остается только инструментом визуальной проверки создаваемых отчетов.

Источники: [Tesseract.js API](https://github.com/naptha/tesseract.js/blob/master/docs/api.md), [PDFium Python API](https://pypdfium2.readthedocs.io/en/stable/python_api.html), [Microsoft MS-DOC2.4.1](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-doc/01d5d8c4-cf9c-4ef9-80fd-439e763cfe01), [xlrd](https://pypi.org/project/xlrd/).
