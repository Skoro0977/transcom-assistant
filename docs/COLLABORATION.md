# Совместная разработка

Основной сервис: закрытый репозиторий [Skoro0977/transcom-assistant](https://github.com/Skoro0977/transcom-assistant). Код и история main загружены 15.11.2026. Локальный origin указывает на https://github.com/Skoro0977/transcom-assistant.git, main отслеживает origin/main.

Локальная main содержит общий принятый результат. Каждый участник работает в своем клоне и короткой ветке, затем создает PR в main. После ревью изменения объединяются и другой участник забирает актуальную main. Так можно работать порознь и сохранять общий результат в одной интеграционной ветке.

GitLab по ответам пользователя не требуется. Аккаунт коллеги пока не предоставлен, поэтому приглашение не отправлено. Для приглашения нужна роль Write без прав владельца. Настройки защиты ветки применяются после создания репозитория в пределах доступного тарифа.

Данные, архив, ключи и учетные записи находятся вне Git. На новом компьютере клонировать код в папку на D, подготовить документированную среду, выполнить scripts/setup.ps1 и добавить личную .env. Локальную базу и исходный архив передавать только согласованным закрытым способом.
