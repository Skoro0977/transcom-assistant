# Совместная разработка

Основной сервис: закрытый репозиторий [Skoro0977/transcom-assistant](https://github.com/Skoro0977/transcom-assistant). Код и история main загружены 15.11.2026. Локальный origin указывает на https://github.com/Skoro0977/transcom-assistant.git, main отслеживает origin/main.

Локальная main содержит общий принятый результат. Каждый участник работает в своем клоне и короткой ветке, затем создает PR в main. После ревью изменения объединяются и другой участник забирает актуальную main. Так можно работать порознь и сохранять общий результат в одной интеграционной ветке.

GitLab по ответам пользователя не требуется. Доступ kozlovskkiy проверен через GitHub API: Write, без прав владельца. T25 закреплена за Ярославом в [задаче №1](https://github.com/Skoro0977/transcom-assistant/issues/1). Настройки защиты ветки применяются после создания репозитория в пределах доступного тарифа.

Данные, архив, ключи и учетные записи находятся вне Git. На основном компьютере использовать D. На компьютере Ярослава без D клонировать ветку feat/portable-windows на C и выполнить setup/start с -Portable по README этой ветки. Ключи задаются в личной .env. Локальную базу и исходный архив передавать только согласованным закрытым способом.


## Компьютер Ярослава без диска D

Для kozlovskkiy подготовлена отдельная ветка feat/portable-windows и явный режим -Portable. На его компьютере допускается локальный C, данные и инструменты размещаются в папке клона. Установку выполнять по README этой ветки и PORTABLE_WINDOWS.md. Прежние пути D в исторической инструкции относятся к рабочему пилоту владельца. Право Write проверено, T25 закреплена за Ярославом. Рабочая база и ключ владельца в Git не передаются.
