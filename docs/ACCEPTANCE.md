## Ограничения и внешние зависимости

Массовый смысловой индекс архива выключен. Автоматическая проверка разрешений отклонила передачу всего корпуса в GigaChat; ожидается прямое разрешение пользователя на эту передачу. Локальный поиск и локальные ответы работают. Готовый облачный индекс не заявляется.

Дополнение от 15.11.2026: код и история main загружены в закрытый репозиторий [Skoro0977/transcom-assistant](https://github.com/Skoro0977/transcom-assistant). Приватность, совпадение локального и удаленного SHA и отсутствие чувствительных файлов в удаленном дереве проверены через GitHub API и Git. Сервер и домен пользователь предоставит позднее. Аккаунт коллеги kozlovskkiy предоставлен, право Write проверено. GitLab исключен по ответам пользователя.

Реальные Gmail, Яндекс, Telegram и ВК не подключены без реквизитов. Проверки этих протоколов использовали искусственные события и подмененные сетевые вызовы. Реальные сообщения людям не отправлялись. Локальный адрес недоступен внешним вебхукам.

В пилотном архиве 188 текущих документов имеют статус ready, 30 содержат предупреждения подготовки, низкой уверенности OCR, геометрии или вложений. Текст получен с 27 сканированных PDF страниц. Полноту инженерных требований и предметные выводы подтверждает руководитель проекта.

Сборка React и авторизованные живые API проверены. Страница входа просмотрена в браузере. Полный визуальный проход после входа не выполнен: инструмент снимка экрана возвращал ошибку, учетные данные не выводились в открытый контекст. Есть некритичное предупреждение сборщика о размере JS пакета.

SQLite/WAL подходит текущему локальному пилоту. Переход на внешний сервер и PostgreSQL требует отдельной проверки переноса и конкурентной работы. Нет утверждения о готовом pgvector, внешнем развертывании или гарантированном отсутствии всех будущих ошибок.
