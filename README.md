# Транскоминжиниринг: помощник руководителя проекта

Локальный пилот для документов, переписки, требований и истории решений. FastAPI, React/Ant Design и SQLite работают одним приложением. Исходники, данные, зависимости, кэши и временные файлы проекта размещены на D.

## Открыть систему

Адрес: [http://127.0.0.1:8000](http://127.0.0.1:8000).

Логины и индивидуальные пароли находятся в закрытом файле `D:\CodexData\Projects\transcom-assistant\data\local\accounts.csv`. Созданы 10 аккаунтов admin и 5 user; в пилотном проекте у всех есть права работы и подтверждения. Пароли и ключи не входят в Git.

Если сервер остановлен, запустите в PowerShell:

```powershell
& 'D:\CodexData\Projects\transcom-assistant\scripts\start.ps1'
```

Оставьте этот терминал работающим. Ctrl+C останавливает приложение. Скрипт применяет миграции и сохраняет существующие учетные записи. Отдельный frontend для обычного использования не нужен: backend отдает готовую сборку.

## Первый проход

1. Выберите проект "Газопровод Ренево". В нем 218 исходных документов: 188 получили текст без статуса подготовки, 30 требуют внимания. Оригиналы и предупреждения доступны в "Документы и письма".
2. Посмотрите "Поиск по проекту" и основания в оригинальных редакциях. Локальный поиск уже работает. Массовый облачный индекс ожидает отдельного разрешения на отправку корпуса.
3. Для анализа отдельного документа используйте его действие анализа. При обращении к GigaChat текст выбранного документа передается провайдеру. Выводы появляются в "Требует проверки" и меняют требования только после явного подтверждения.
4. В "Требования" доступны редакции и основания. "Этапы и задачи", "История событий" и "Риски и уведомления" используют подтвержденные данные проекта.
5. В "Чат по проекту" можно найти основания или подготовить изменение выбранной карточки. Подготовка и подтверждение выполняются отдельно. В "Сводка и отчет" задайте период и выгрузите DOCX.

Отдельный проект "Демонстрация: искусственный объект" содержит проверенный пример: новый документ, анализ GigaChat, подтверждение, перенос срока через чат и вторая редакция. Его решения относятся только к искусственному примеру. В пилотном архиве инженерные требования автоматически не подтверждались.

## Разработка

Корень: `D:\CodexData\Projects\transcom-assistant`.

```powershell
. 'D:\CodexData\Projects\transcom-assistant\scripts\dev-env.ps1'
```

Команда выбирает рабочую папку и переносит TEMP, Python/npm/OCR кэши на D. Для повторной установки зависимостей и сборки выполните `scripts/setup.ps1`. Используются Python 3.11 и переносимая Node 26.13.1 LTS из `D:\CodexData\Runtimes\node\node-v26.13.1-win-x64`. Зависимости закреплены в `requirements.lock` и npm lock-файлах.

Для разработки frontend в отдельном терминале после подключения dev-env:

```powershell
npm --prefix apps/web run dev
```

Проверки из корня после dev-env:

```powershell
& '.venv\Scripts\python.exe' -B -m ruff check apps/api scripts tests migrations/env.py
& '.venv\Scripts\python.exe' -B -m pytest tests --basetemp 'D:\CodexData\Temp\transcom-build\pytest-manual'
npm --prefix apps/web run build
```
